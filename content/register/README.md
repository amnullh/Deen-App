# Register fragments

Rows for `content/LICENSES.md` that were added in parallel are kept here, one Markdown file per
workstream (for example `content/register/planner.md`). `tools/license_scan` and
`tools/sync_content` read `content/LICENSES.md` and every file in this folder as one register.
Use the same row format as `content/LICENSES.md`, and fold the rows into the main file when the
workstreams are merged.
